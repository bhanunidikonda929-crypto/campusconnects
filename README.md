## About Project
CampusConnect is a College Notice Board Website where students, faculty and admin can post, view and manage college notices in one place. No need for WhatsApp groups or paper notices.

## Features
- Student / Faculty / Admin Roles
- Post, Edit, Delete Notices
- Search & Filter by Department, Category, Priority
- Dashboard with Real Statistics
- Department-wise Notices (CSE, ECE, EEE, MECH, CIVIL)
- LocalStorage Persistence - Data stays after refresh
- Mobile Responsive Design

## How to Run
1. Download or Clone this repo
2. Just open `index.html` in any browser
3. No installation needed

OR directly open Live Link:
